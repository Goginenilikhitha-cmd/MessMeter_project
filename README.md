# MessMeter - Zero Waste Mess Hack

MessMeter is a hostel mess management website that helps reduce food waste.

Students can opt-in / opt-out of meals, view menus, rate dishes and give feedback.

Mess staff can predict daily headcount, track food waste and plan the correct quantity of food to cook.

## Features

- Homepage and navigation
- Today's menu and 7-day weekly menu
- Student meal opt-in / opt-out selection
- Daily headcount predictor (enrolled - opt-outs)
- Food waste logging in kilograms
- Dish ratings (1-5) and feedback
- Waste analytics using charts

## Static Website

- Built with HTML and CSS
- Responsive layout for mobile and desktop
- Homepage, Menu page, Feedback page
- Weekly menu table with day-wise meals
- Clean and simple UI for students and mess staff

## Dynamic Website

- Built using vanilla JavaScript
- Meal opt-in / opt-out updates headcount in real time
- Headcount predictor calculates: Enrolled Students - Opt-outs
- Waste log updates total waste and chart automatically
- Ratings and feedback are stored and displayed instantly
- Form validation for waste entry and feedback form
- http://Chart.js used for waste analytics

## Files

- http://index.html - Homepage with navigation and today's menu
- http://menu.html - 7-day weekly menu page
- http://headcount.html - Meal opt-in / opt-out and headcount predictor
- http://waste.html - Food waste logging and analytics
- http://feedback.html - Dish ratings and feedback form
- http://style.css - Styling for all pages
- http://script.js - Logic for headcount, waste, ratings and charts

## Tech Stack

- HTML, CSS, JavaScript
- http://Chart.js for Waste Analytics

## How to Run

1. Extract MessMeter_Complete.zip
2. Open the extracted folder in VS Code
3. Open http://index.html
4. Right-click http://index.html -> Open with Live Server
5. OR double-click http://index.html to open in browser
6. Internet required for http://Chart.js
